<h1 align="center">Mac Pulse</h1>
<p align="center">CPU, memory, disk, and network readings in your Mac’s menu bar.</p>
<p align="center"><strong>macOS 14 or later</strong> · Apple silicon and Intel · Free</p>

## Getting Mac Pulse

The first public download is in preparation. When version 1.0 is available, you’ll find the app ZIP under **Assets** on the [Releases page](https://github.com/shrotshahariar/Mac-Pulse/releases).

## Inside the dashboard

| To see… | Open… |
| --- | --- |
| How busy each CPU core is | **Processor load** for a per-core breakdown and history. |
| Which apps are using the most memory | **Memory usage** for a graph and the five largest measured apps. |
| How much space is left | **Disk usage** for capacity, available storage, and application sizes. |
| How fast data is moving | **Network activity** for upload and download speeds. Hover over the graph to inspect a reading. |
| How much data you’ve transferred | **Network Data** for today, the last 7 days, and the last 30 days while the app was running. |

In **Settings → Menu bar**, choose which readings appear together. Show both network directions or just one, in bits or bytes per second. Turn all readings off to keep only the pulse icon.

## Privacy

Monitoring history stays on your Mac. CPU and memory history covers up to 30 days while the app runs. Choosing **Show public IP** contacts ipify to look up your public address.
